── СПРАВКА ПО КОЭФФИЦИЕНТАМ ──
Показаны только сильные и умеренные связи; слабые отфильтрованы.

Коэффициент Пирсона (r) (от −1 до +1)
  Линейная связь двух числовых столбцов. +1 — рост одного сопровождается ростом другого, −1 — рост одного сопровождается падением другого, 0 — линейной связи нет.
  Пороги: Сильная: |r| ≥ 0.7. Умеренная: 0.4 ≤ |r| < 0.7. Слабые связи скрыты.

Cramér's V (от 0 до 1)
  Сила связи между двумя категориальными столбцами. Чем выше V, тем предсказуемее значения одного столбца по другому (например, регион и канал продаж).
  Пороги: Сильная: V ≥ 0.5. Умеренная: 0.3 ≤ V < 0.5. Слабые связи скрыты.

Корреляционное отношение (η) (от 0 до 1)
  Насколько категориальный столбец объясняет разброс числового. Высокое η — средние/медианы числа заметно различаются между группами.
  Пороги: Сильная: η ≥ 0.5. Умеренная: 0.3 ≤ η < 0.5. Слабые связи скрыты.
